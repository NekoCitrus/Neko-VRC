## v2.0.0 · WinUI 3 更新

- 默认前端迁移至 WinUI 3，使用原生导航、标题栏及切页动画，优化三列触发项和紧凑布局。
- 新增浅色、深色、跟随系统主题，切换即时生效并独立保存，不重启设备服务。
- 郊狼与负鼠保留独立 A/B 通道、App / 蓝牙连接方式和强度上限；新增与输入框同步的 0～200 滑块。
- 郊狼新增“纯粹”波形作为首项与新配置默认值，保留已有波形选择。地图事件使用恒定幅值输出，结束后恢复 SPS 预设波形。
- OSCQuery 部位列表及数量只统计可读、可计算深度的插座与插头；顶部统一显示等待、回退建议及无可用参数提示。
- 修复参数目录变化时误清空整个深度计算器的问题；LMS 归零、超时或相关信号移除不会连带清除其他有效 SPS 输入。
- PCS、LMS、参数/地图事件新增帮助图标；调试页仅显示可伸缩日志框。
- 配置保存至 Neko-VRC 目录，发布产物统一放在 products；关闭退出时立即隐藏窗口，在后台完成清理。

### 下载

- **推荐：`Neko-VRC-WinUI-v2.0.0-win-x64.zip`**。完整解压后运行 `Neko-VRC.exe`，已包含 Python 后端、.NET 与 Windows App Runtime。
- `Neko-VRC-WPF-win-x64.zip` 为此前发布的旧 WPF 兼容包，保留供回退使用，不包含本轮全部界面和修复。

### 验证

208 项自动化测试通过；验证了 Socket 地图事件报文、两种主题下五个页面与三种窗口尺寸、24 次快速切页、主题即时保存、滑块同步、热应用及关闭清理。未进行实体设备和游戏内实测。
